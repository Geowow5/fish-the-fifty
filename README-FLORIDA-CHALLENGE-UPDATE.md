Florida Challenge Update

This update adds the Florida FWC angler recognition guide at /states/florida/challenge.

The page covers Big Catch, TrophyCatch, and Catch a Florida Memory. Its local checklist tracks Big Catch species, TrophyCatch bass, the 75-species Saltwater Fish Life List, 30 Reel Big Fish targets, and nine Grand Slams.

The homepage Featured Adventures list remains alphabetical, and Florida now links to its challenge page from the state directory and homepage.

The Google Search Console verification file remains at public/googledac4fab3e6ec5bd2.html.
