# Arizona Trout Challenges update

This update adds the AZGFD Arizona Trout Challenge and Wild Trout Challenge at `/states/arizona/challenge`, including separate progress tracking for the 6-of-8 and five-wild-species goals. The tracker records catch date, water, gear, and release status locally in the browser; it does not store catch photos or submit applications.

The page links to AZGFD's challenge map, official application, Fish & Boat water finder, native-trout surveys, and current fishing information. It is linked from the alphabetized featured adventures, homepage state grid, and state directory.

To update the current Vercel project, upload the extracted ZIP contents to the repository root. Existing Google verification and Vercel Analytics files are preserved.
