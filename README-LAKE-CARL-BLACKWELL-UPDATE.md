# Fish the Fifty — Lake Carl Blackwell update

This update adds a new Oklahoma water guide at `/states/oklahoma/lake-carl-blackwell` and links it from the Oklahoma state page.

## Included

- OSU-operated Lake Carl Blackwell access, permit, and regulation guidance
- Ski Point, Blackjack Cove, and public shoreline access cards with map links
- Fly-fishing starting tactics for bass, sunfish, crappie, catfish, and saugeye
- Links to the OSU general and no-wake maps, FAQ, permits, regulations, Oklahoma license portal, and ODWC fishing reports
- `package-lock.json` and this README are included for the upload

## Upload

Upload the ZIP contents to the repository root, preserving the `app/`, `public/`, `package.json`, `package-lock.json`, `tsconfig.json`, and `next-env.d.ts` paths. Do not upload the ZIP as a nested file or upload `.next/` and `node_modules/`.
