# Georgia Bass Slam update

This update adds Georgia’s official Bass Slam at /states/georgia/challenge. The guide covers the ten eligible species, official location and identification resources, grouped-species rules, legal catch and size requirements, photo requirements, and the calendar-year deadline.

The private browser checklist tracks species, catch date, water, and length. It does not store photos or submit an entry to Georgia DNR.

Georgia is linked from the alphabetized Featured Adventures, the homepage state grid, and the state directory. The Google Search Console verification file and Vercel Analytics dependency are preserved.
