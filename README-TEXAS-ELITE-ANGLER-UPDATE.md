# Fish the Fifty — Texas Elite Angler update

This update adds the Texas competition page at `/states/texas/challenge` and links it from the Texas state card in the state directory.

## Included

- Dark-mode Texas Elite Angler challenge page
- Local-browser progress tracker for five distinct Big Fish Award species
- Freshwater and saltwater divisions, with TPWD published qualifying length minimums
- Catch date and waterbody fields, duplicate species feedback, minimum-length feedback, and save/clear controls
- Official TPWD award, application, and fishing resource links
- Separate Toyota ShareLunker spotlight

## Upload

Upload the ZIP contents to the repository root, preserving the `app/`, `public/`, `package.json`, `package-lock.json`, `tsconfig.json`, and `next-env.d.ts` paths. Do not upload the ZIP as a nested file or upload `.next/` and `node_modules/`.

TPWD controls catch eligibility and award decisions. Confirm current requirements and submit official applications within the required time after each catch.
