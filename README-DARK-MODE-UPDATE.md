# Fish the Fifty — Dark mode update

This update applies a dark palette across the home page, state directory, Oklahoma guides, Winter Trout page, and challenge tracker. Teal and moss accents stay bright for contrast, while the winter stocking notice keeps a muted amber highlight.

## Upload

Upload the ZIP contents to the repository root, preserving the `app/`, `public/`, `package.json`, `package-lock.json`, `tsconfig.json`, and `next-env.d.ts` paths. Do not upload the ZIP as a nested file or upload `.next/` and `node_modules/`.
