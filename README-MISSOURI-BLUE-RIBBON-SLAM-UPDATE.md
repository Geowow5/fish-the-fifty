# Missouri Blue Ribbon Trout Slam update

This update adds the dedicated Missouri challenge page at `/states/missouri/challenge` and a redirect from `/states/missouri`. It wires Missouri from the homepage and state directory, lists all nine current MDC Blue Ribbon Trout Areas with their qualifying reaches and official regulation links, and adds a private browser checklist.

The page reflects the MDC award milestones (5, 7, and 9 waters), its current catch and release rules, and the published Spring Creek access note. Confirm regulations, access, and stream boundaries with MDC before each trip.

To update the existing Vercel project, upload the extracted ZIP contents to the repository root. The package preserves the existing Google verification file and Vercel Analytics setup.
