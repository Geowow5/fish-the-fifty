# Ohio Fish Ohio challenge update

This build adds `/states/ohio/challenge`, a complete guide to Ohio's Fish Ohio and Master Angler recognition program.

## Included

- Current 2026–27 qualifying lengths for 26 eligible species
- Separate Lake Erie and inland thresholds where ODNR publishes different standards
- A four-species Master Angler tracker with duplicate and minimum-length checks
- Browser-local saving, official application links, and Ohio navigation updates
- All earlier challenge pages, Oklahoma guides, logo assets, and Google verification file
